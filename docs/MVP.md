# MVP

## Objectif

Prouver qu'un petit corpus peut être exploré, vérifié et enrichi sans matrice exhaustive ni génération opaque.

## Périmètre fonctionnel

1. trois thèmes pilotes ;
2. cinquante sources maximum ;
3. cent affirmations reliées à des extraits ;
4. vingt arguments avec objections ;
5. recherche et filtres par thème, type et statut ;
6. page détaillée affichant provenance et incertitude ;
7. formulaire de proposition soumis à validation ;
8. historique minimal des changements.

Le formulaire de proposition et l'historique minimal sont actuellement assurés par `/contribuer`, les issues GitHub et les commits associés. Une proposition y reste explicitement distincte d'un contenu validé.

## Thèmes pilotes proposés

- écologie et conditions matérielles ;
- IA et avenir du travail ;
- sentiment d'impuissance politique.

Ils couvrent des questions factuelles, économiques, philosophiques et stratégiques sans obliger le MVP à traiter immédiatement toutes les controverses du projet.

## Non-objectifs

- génération de dizaines de milliers d'arguments ;
- fine-tuning ou QLoRA ;
- estimation automatique de croisements sans données suffisantes ;
- personnalisation individuelle ;
- système de réputation complexe.

## Critères de réussite

- la provenance d'une affirmation est accessible en deux actions maximum ;
- un relecteur peut signaler précisément une source insuffisante ;
- un argument présente au moins une objection sérieuse ;
- les catégories et filtres sont compréhensibles sans formation ;
- aucune information sensible n'est requise pour utiliser le produit.
